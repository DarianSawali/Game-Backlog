# Archived design prototypes

These files preserve earlier interface experiments without exposing them as live Next.js routes or including them in application compilation.

- `console-preview`: early console and arcade hybrid
- `console-showcase`: functional console-library exploration
- `design-preview`: theme comparison gallery
- `game-menu`: standalone preview of the design now used by the main page

The `.archive` suffix is intentional. Restore a file's `.tsx` extension and move it back under `src` before reusing it.
